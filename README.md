# **Good List System** 
— *Check That Box*

---

Welcome to **Good List System** — a simple yet highly questionable to-do app! Your mission, should you choose to accept it, is to dive into this project and show us what you're made of. Think of it as a treasure hunt… where the treasure is finding bugs and fixing them.

---

### **What is this?**
Good List System is a **to-do app**. You know, the classic:
1. Write tasks.
2. Check tasks off when done.
3. Feel productive.

But don’t let its simplicity fool you — there are a few "opportunities for growth" (read: bugs and bad practices) sprinkled in here. We want you to spot them, fix them, and let us know what you did.

---

### **What's the Deal?**
This app consists of two parts:
1. **Backend**: A .NET Core API with controllers to handle authentication and task management. (Yes, there's a mock login. No, you won't actually hack the NSA.)
2. **Frontend**: A Vue.js app — handcrafted, lovingly disorganized, and screaming for some refactoring.

---

### **What We’d Like from You**
- **Step 1**: Set it up, run it, and get a feel for the app.
- **Step 2**: Explore the code. Fix what’s broken, improve what isn’t broken (*but probably will sooner rather than later*), and make it awesome.
- **Step 3**: Tell us what you did! Write a brief explanation of the issues you found, how you fixed them, and why your changes matter.

---

### **Getting it running**
Getting running is made to be as smooth as possible.

There are three options.
- **Option 1**: Use dotnet from the command-line: `dotnet run --project .\src\QuickTask.csproj`
- **Option 2**: Open the `quick-task.sln` file in your favorite IDE and hit F5.
- **Option 3**: Build the `Dockerfile` and run the image (*map port 8080 to your host*).

---

### **Final Words**
Remember, this is less about finding all the bugs (though kudos if you do) and more about seeing how you approach solving problems and improving code. If you have fun while doing it, even better!

Good luck, and happy debugging. 🚀
